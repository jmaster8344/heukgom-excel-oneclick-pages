개인정보처리방침

제품: 흑곰선생 엑셀 원클릭 / Heukgom Excel OneClick 0.1.0

운영 브랜드: 흑곰선생 · 시행일: 2026-10-06

이 확장프로그램은 사용자가 현재 웹페이지에서 요청한 Excel/CSV 다운로드 버튼 탐색과 클릭을 돕습니다. 처리 기능은 사용자의 기기에서 수행하며, 개발자의 서버나 분석 서비스로 페이지 정보를 전송하지 않습니다.

기기에서 일시 처리하는 정보

사용자가 실행을 요청하면 현재 최상위 문서의 클릭 가능한 요소에 한해 텍스트, 버튼 값, title, aria-label, download, href 속성을 검사합니다. 이를 통해 파일 형식 및 다운로드 관련 문구를 판단합니다. 후보 문구는 사용자가 선택할 수 있도록 확장 팝업에 표시됩니다. 후보 참조와 검사 결과는 현재 문서의 메모리에서만 사용하며 클릭 후 소모되거나 2분 후 만료됩니다. 검사 대상 링크 속성에 포함된 정보는 외부로 보내거나 저장하지 않습니다.

로그인 ID·비밀번호 입력칸, 쿠키, 인증 토큰 저장소, 판매·정산 표 데이터, 다운로드 파일 내용 및 전체 브라우징 기록을 읽거나 수집하는 기능은 제공하지 않습니다. 모든 input 값을 읽는 방식이 아니라 button/submit 타입의 버튼 값만 검사합니다.

선택적으로 기기에 저장하는 정보

“화면에서 다운로드 버튼 직접 지정”을 사용하면 해당 사이트의 hostname과 선택한 버튼을 찾기 위한 구조적 CSS selector를 chrome.storage.local에 저장합니다. selector에는 요소의 태그·구조적 순서만 사용하고 사용자 ID, 버튼 문구, 링크 주소, 임의 데이터 속성은 저장하지 않습니다. Chrome 계정 동기화 저장소는 사용하지 않습니다.

저장 정보는 사용자가 해당 사이트의 “기억 지우기”를 누르거나 확장프로그램을 삭제할 때까지 유지합니다. 다른 hostname의 기억은 재사용하지 않습니다. 저장 위치는 페이지 구조 변경으로 달라질 수 있어, 다시 검사하고 애매한 후보는 사용자 선택을 받습니다. 호스트별로 한 개의 버튼 위치만 기억합니다.

외부 전송 및 제3자

확장 자체에는 외부 서버 요청, 광고, 분석 SDK, 추적 및 데이터 판매 기능이 없습니다. 개인정보를 개발자 또는 제3자에게 전송하거나 공유하지 않습니다. 사이트의 원래 다운로드 버튼을 클릭한 후 발생하는 사이트 통신과 파일 다운로드에는 그 사이트의 정책과 브라우저의 동작이 적용됩니다.

Chrome Web Store Limited Use 준수

흑곰선생 엑셀 원클릭은 Chrome Web Store User Data Policy와 Limited Use 요구사항을 준수합니다. 확장 기능 제공에 필요한 범위를 넘어 사용자 데이터를 사용·전송·판매하지 않으며, 광고·신용평가·목적 외 프로파일링 또는 제3자 데이터 판매에 사용하지 않습니다. 사용자가 요청한 현재 페이지의 다운로드 버튼 탐색·실행 및 사용자가 명시적으로 선택한 버튼 위치 기억 외의 목적으로 데이터를 사용하지 않습니다.

권한과 보안

activeTab은 사용자가 확장을 호출한 탭의 일시 접근, scripting은 요청한 버튼 탐색/선택기 삽입, storage는 직접 지정 기억에 사용합니다. 전체 사이트 상시 접근, cookies, downloads, 브라우징 기록 권한을 요청하지 않습니다. 저장소는 기기 내부 Chrome 저장소이며 별도의 암호화 저장 기능을 제공하지 않습니다. 민감한 값이 selector에 포함되지 않도록 구조적 selector만 저장합니다.

문의 및 변경

문의는 Chrome Web Store 제품 페이지의 개발자 연락처를 이용해주세요. 처리 기능이 변경되면 이 문서의 시행일과 설명을 업데이트합니다.
